# CIBER PISTE POS

Sistema POS web modular para CIBER PISTE.

**Proyecto completamente independiente de THOP.**

## Stack
- Next.js + TypeScript
- PostgreSQL / Supabase
- Vercel
- PWA

## Módulos
- Ventas y caja
- Inventario
- Productos y categorías
- Servicios
- Compras y proveedores
- Roles y permisos
- Reportes
- Cierre diario por sección
- Rotación y sugerencias de compra
- Auditoría

## Estado
Arquitectura V1 en construcción.
